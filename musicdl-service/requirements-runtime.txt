# musicdl 2.14.2 的**运行期**依赖：等价于 `pip install musicdl==2.14.2` 自动解析
# 出来的依赖树，只剔除两个体积巨大但本服务一次都用不到的 wheel。
#
# 为什么不能直接用 requirements.txt 装：
#   * nodejs-wheel / nodejs-wheel-binaries —— aarch64 wheel 单份 57.8MB（x86_64
#     58.3MB）。musicdl 里唯一的用处是 youtubeutils 的
#     `shutil.which("node") or shutil.which("nodejs")`——找一个系统 Node 去跑
#     YouTube 的 JS 协商。而镜像里已经装了 Node v22（`/usr/local/bin/node`），
#     飞牛宿主机也自带 nodejs_v26，再装一份纯属重复。
#   * av（PyAV）—— wheel 自带一份完整的 FFmpeg 共享库，aarch64 约 42MB /
#     x86_64 约 38MB（压缩后）。musicdl 只在 tidalutils.py 的
#     `if TYPE_CHECKING:` 分支里 `import av`，运行期从不使用；真正的转封装走
#     系统 ffmpeg（`shutil.which("ffmpeg")`），容器里由 apt 提供、宿主由
#     ensure_sources_native.sh 检查。
#
# 两者合计约 100MB（压缩后），功能零损失。
#
# 升级 musicdl 时请重新核对本清单：
#   pip show musicdl          # 看 Requires: 一行
#   pip install -q --dry-run --ignore-installed musicdl==<新版本> --report - | ...
